# My Simple Home

Projeto bem simples contendo meu card responsivo.
![my-card](image.png)

## Objetivo

- Antes eu tinha no ar um site onde havia o botão de acessar meus repositórios do github,
  agora neste Projeto além do botão de acesso ao meu github, tem um card responsivo onde
  falo um pouco sobre mim e tem um botão para exibir a listagem dos repositórios.
